# 🌸 Cherry Blossom

### An AI-first PCB design tool with a modern UI

Cherry Blossom combines a discoverable, Figma-style interface with the depth professional EDA
tools demand — built for hobbyists at home and hardware engineers at work.
Describe a circuit in plain English, refine in chat.

## Download

Grab the build for your platform from the [**latest release**](https://github.com/cherryblossomhq/releases/releases/latest):

- **macOS (Apple Silicon)** — the `.dmg` whose name ends in `aarch64`
- **macOS (Intel)** — the `.dmg` whose name ends in `x64`
- **Windows** — the `.exe` / `.msi` installer

Previous versions live on the [releases page](https://github.com/cherryblossomhq/releases/releases).

### macOS note

Builds are ad-hoc signed, so on first launch macOS may warn that the app is from an
unidentified developer. Right-click the app → **Open**, or allow it under
**System Settings → Privacy & Security**.

## Updates

Cherry Blossom updates itself. When a new release is published here, the installed app
detects it and offers to download and apply the update — no manual reinstall needed.
